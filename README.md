# 债券周报 Mac版 14.3

一个本地运行的债券周报自动化工具。公开版保留生成引擎、交易所公开数据抓取、快照校验、模板驱动填充、Web 工作流和回归测试；不包含任何真实业务文件、历史数据库、任务记录、生产模板或输出成品。

## 公开版与生产版的区别

公开版没有预置特定券商优先级、高亮机构、法人简称例外或内部确认文件号映射。需要这些行为时，请通过配置或环境变量自行设置。这样既保留完整工程能力，也避免把特定机构的生产口径固化到公开仓库。

## 安装与启动

要求 Python 3.9+。macOS 可双击 `启动Web.command`；也可以：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.web.app:app --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`。公开版默认只监听本机，未实现局域网认证；不要直接暴露到公网。

## 使用数据

程序运行时由用户自行上传本周数据和上一期 Excel 模板。`input/简称.xlsx` 只包含虚构示例，可替换成自己的 `full -> short` 精确映射。运行生成的数据库、模板副本、任务和结果都已在 `.gitignore` 中排除。

如需设置某个承销商优先排序，可在启动前设置：

```bash
export WEEKLY_PRIORITY_UNDERWRITER="示例证券"
```

默认不设置任何特定机构。

## 测试

```bash
python -m unittest discover -s tests -v
```
